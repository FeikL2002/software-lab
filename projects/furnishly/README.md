# Furnishly

A local pre-owned furniture marketplace interface.

## Status

Customized product prototype source. Example listings/profile content are demonstration content. Existing framework commands require the original Sites adapter and hosting configuration, which are omitted. There is no verified public marketplace, moderation, entry/payment operation, fulfillment, or production service. Original generated build output and private hosting state are not included.

## Stack

React/TypeScript, Vinext, Cloudflare Workers/D1; Node.js 22.13+.

## Local startup

Run these commands from this project directory. Read the status above first; source archives with omitted hosting adapters require restoration before these framework commands can succeed.

```sh
npm ci
npm run dev
```
