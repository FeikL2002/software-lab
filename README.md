## Validation and omissions

See [VALIDATION.md](VALIDATION.md) for the checks actually performed. No app was deployed, no external providers were contacted, and no private records were imported during staging. Payment, account, provider, camera, email, marketplace and delivery behavior require separate setup and verification.

The collection excludes dependencies, compiled bundles where editable source exists, vendor libraries, private environment files, hosting metadata, browser captures, logs, runtime databases, lead lists, customer records, mailbox data, ticket records, campaign materials and coursework. Static `dist/` folders are retained for four apps because those folders hold their editable source.

No root software license was present. This collection does not add a license grant; see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
